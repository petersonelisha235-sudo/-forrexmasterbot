# Timestamp Converter Bot

An educational Telegram bot that teaches date and time handling in programming.

## Features
- Convert Unix timestamps to human-readable dates
- Learn what Unix time is and why it matters
- Timezone basics for Python and JavaScript
- Interactive quiz on Unix Epoch

## Deployment
Hosted on Railway. Environment variable required:
- `TELEGRAM_BOT_TOKEN`

## Commands
- `/start` - Main menu
- `/help` - Usage guide
- `/settings` - Bot settings
